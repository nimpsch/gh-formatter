# Security Policy

## Supported versions

gh-formatter is pre-1.0; security fixes are applied to the latest released
version only. Please upgrade to the newest release before reporting an issue.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, report privately via GitHub's
[private vulnerability reporting](https://github.com/nimpsch/gh-formatter/security/advisories/new)
("Report a vulnerability" under the Security tab). If that is unavailable,
contact the maintainer directly.

Please include:

- A description of the issue and its impact
- Steps to reproduce (a minimal input file, if applicable)
- The gh-formatter and Python versions affected

We will acknowledge your report as soon as possible and keep you updated on
the fix. Thank you for helping keep the project and its users safe.
